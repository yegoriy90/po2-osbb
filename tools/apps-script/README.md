# Сторінка підтвердження власників (Google Apps Script)

Проста сторінка лише для тебе: **фото документів → Claude розпізнає → перевіряєш форму → «Підтвердити»** →
дані записуються в реєстр, фото — на твій Google Drive, відсоток оновлюється на сторінці й на po2.kyiv.ua.

Файли: `Code.gs` (сервер), `Page.html` (сторінка).

## Налаштування (один раз, ~15 хв)

1. **Ключ Claude API.** console.anthropic.com → Billing (поповнити на $5–10) → API Keys → Create Key.
2. Відкрий реєстр (registry_v11) у Google Sheets → **Розширення → Apps Script**.
3. Файл `Code.gs`: видали все, встав вміст `Code.gs` з репозиторію.
   **＋ → HTML** → назва `Page` → встав вміст `Page.html`. Збережи (Ctrl+S).
4. ⚙️ **Налаштування проєкту → Властивості скрипту → Додати**: `ANTHROPIC_API_KEY` = ключ.
5. Угорі вибери функцію **`setup`** → **Виконати** → дозволь доступ («Додатково → Перейти до проєкту»).
   Вона додасть колонку «ДАХ вручну» (L у реєстрі, F у нежитлових), оновить формули «ДАХ» і створить аркуш «Заявки».
6. **Розгорнути → Нове розгортання → Веб-застосунок**:
   - Виконувати як: **Я**
   - Хто має доступ: **Усі** (сторінку все одно відкриєш лише ти — скрипт пускає тільки власника;
     усім іншим доступні тільки загальні цифри для сайту)
   - **Розгорнути** → скопіюй URL веб-застосунку.
7. Збережи URL у закладках телефона — це і є твоя сторінка.
8. Надішли URL Claude (або встав у `data.js` → `statsUrl: "<URL>?stats=1"`), щоб po2.kyiv.ua показував живий відсоток.

Після зміни коду: **Розгорнути → Керування розгортаннями → ✏️ → Версія: нова → Розгорнути** (URL не зміниться).

## Як працює

- **Голос** = «✅ У ДАХ» + «Право власності». «В ДАХ» — з експорту ДАХ **або** галочка «ДАХ вручну»,
  яку сторінка ставить при підтвердженні (людина, яка прислала документ, щойно зареєструвалась у ДАХ,
  а в експорті її ще немає).
- Перед підтвердженням сторінка показує, що зараз у реєстрі, і попередження:
  ❗ не право власності, ❗ чужа адреса, ❗ № немає в реєстрі, інша площа, інший власник, «вже підтверджено».
  Поля можна виправити вручну.
- Інвестиційні / попередні договори внести не можна (кнопка неактивна).
- Кожне підтвердження — рядок у «Заявки» з посиланням на папку з фото («ДАХ документи» на Drive).
- `?stats=1` віддає лише суми по секціях і площу — без номерів квартир і ПІБ (як `votes.js`). Кеш 5 хв.

## Вартість і приватність

- Модель `claude-opus-5-5`, ~$0,02–0,04 за комплект фото.
- Фото стискаються в телефоні до 2000 px і зберігаються лише на твоєму Google Drive; для розпізнавання
  йдуть у Claude API (Anthropic не використовує дані API для навчання).
- У коді немає ключа й персональних даних.
