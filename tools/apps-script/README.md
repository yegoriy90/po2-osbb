# Розпізнавання документів власників → реєстр

`docs_intake.gs` — Google Apps Script для таблиці-реєстру (registry_v11 у Google Sheets).
Фото витягу / ДКП / договору з УК кладеш у папку на Google Drive → скрипт розпізнає їх через Claude
і додає рядок на аркуш «Заявки» → ставиш ☑ «Підтвердити» → площа, ПІБ і статус «Право власності»
самі потрапляють у «Реєстр мешканців» (або «Нежитлові приміщення»).

## Налаштування (один раз, ~10 хв)

1. **Ключ Claude API.** console.anthropic.com → Billing (поповнити на $5–10) → API Keys → Create Key. Скопіюй ключ.
2. Відкрий реєстр у Google Sheets → **Розширення → Apps Script**.
3. Видали все в `Code.gs` і встав вміст `docs_intake.gs`. Збережи (Ctrl+S).
4. ⚙️ **Налаштування проєкту → Властивості скрипту → Додати властивість**:
   `ANTHROPIC_API_KEY` = твій ключ. Збережи.
5. Угорі вибери функцію **`setup`** → **Виконати** → дозволь доступ (Google попросить підтвердити, бо скрипт твій і неперевірений — «Додатково → Перейти до проєкту»).

Після цього з'являться папки на Drive «ДАХ документи — нові» і «ДАХ документи — оброблені» та аркуш «Заявки».

## Щоденна робота

- **Один документ** — просто збережи фото в папку «ДАХ документи — нові» (з телефона: Поділитися → Диск).
- **Кілька фото одного власника** (витяг + договір з УК) — створи в «нові» підпапку (назва будь-яка, напр. `165`) і поклади їх туди. Скрипт розгляне їх разом.
- Раз на 10 хв скрипт обробляє до 3 комплектів, файли переносить в «оброблені».
- На аркуші «Заявки» дивишся колонку **⚠ Перевірити** і ставиш ☑ **Підтвердити**. У колонці «Внесено» з'явиться ✅ і час.
- ❗ у «Перевірити» — не підтверджуй наосліп: відкрий фото за посиланням.

Скрипт **не вносить** у реєстр:
- інвестиційні / попередні договори (не право власності);
- номери, яких немає в реєстрі (внеси вручну).

## Вартість і приватність

- Модель `claude-opus-5-5`, ~$0,02–0,04 за комплект фото. На весь будинок — кілька доларів.
- Фото зберігаються лише на твоєму Google Drive. Для розпізнавання вони передаються в Claude API (Anthropic не використовує дані API для навчання моделей).
- `deleteAfterApprove: true` у `CFG` — фото автоматично йдуть у кошик після підтвердження.
- У коді немає ключа й персональних даних, тому він може лежати в публічному репозиторії.

## Якщо щось не так

- Рядок «❗ Помилка: …» — відкрий фото за посиланням, перенеси назад у «нові», щоб спробувати ще раз.
- iPhone-фото (HEIC) і великі фото скрипт бере через прев'ю Google Drive; якщо прев'ю ще не готове, файл просто почекає наступного запуску.
- Журнал запусків: Apps Script → **Виконання**.
