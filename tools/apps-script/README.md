# Сторінка підтвердження власників (Google Apps Script)

Проста сторінка лише для тебе: **фото документів → сторінка розпізнає (безкоштовно через OCR Google або через Claude) → перевіряєш форму → «Підтвердити»** →
дані записуються в реєстр, фото — на твій Google Drive, відсоток оновлюється на сторінці й на po2.kyiv.ua.

Файли: `Code.gs` (сервер), `Page.html` (сторінка).

## Налаштування (один раз, ~15 хв)

**0. Перетвори таблицю на Google-таблицю.** `registry_v10.xlsx` — це Excel-файл, до нього не можна прив'язати скрипт.
Відкрий його → **Файл → Зберегти як Google Таблиці**. З'явиться нова Google-таблиця з тим самим вмістом
(нове посилання) — далі працюєш у ній, а xlsx можна перейменувати на «архів».

1. У новій Google-таблиці: **Розширення → Apps Script**.
2. Якщо там уже є код автофарбування (`onEdit`) — **не видаляй його**. Натисни **＋ → Скрипт**, назви `Pidtverdzhennia`
   і встав туди вміст `Code.gs`. Потім **＋ → HTML** → назва `Page` → встав `Page.html`. Збережи (Ctrl+S).
3. **Служби (＋ зліва) → Drive API → Додати** — безкоштовне розпізнавання тексту (OCR) Google.
4. *(Необов'язково)* ⚙️ **Налаштування проєкту → Властивості скрипту → Додати**: `ANTHROPIC_API_KEY` = ключ з
   console.anthropic.com. Без ключа сторінка працює безкоштовно через OCR; з ключем — розпізнає Claude (точніше).
5. Угорі вибери функцію **`setup`** → **Виконати** → дозволь доступ («Додатково → Перейти до проєкту (небезпечно)» —
   це твій власний скрипт). З'явиться аркуш «Заявки».
6. **Розгорнути → Нове розгортання → ⚙️ Веб-застосунок**:
   - Виконувати як: **Я**
   - Хто має доступ: **Усі** (сторінку все одно відкриєш лише ти — скрипт пускає тільки власника;
     усім іншим доступні тільки загальні цифри для сайту)
   - **Розгорнути** → скопіюй URL веб-застосунку (закінчується на `/exec`).
7. Відкрий URL на телефоні й додай на головний екран (Поділитися → На початковий екран) — це твоя сторінка.
8. Надішли URL Claude — він під'єднає живий відсоток на po2.kyiv.ua (`statsUrl` у `data.js`).

Після зміни коду: **Розгорнути → Керування розгортаннями → ✏️ → Версія: нова → Розгорнути** (URL не зміниться).

## Два режими розпізнавання

| | Безкоштовно (за замовчуванням) | З ключем Claude |
|---|---|---|
| Як | OCR Google Drive + розбір тексту за шаблоном | Claude читає документ «як людина» |
| Ціна | 0 | ~$0,02–0,04 за комплект (`claude-opus-5-5`); з `claude-haiku-5-5` у `CFG.model` — ~$0,001, але мінімальне поповнення $5 |
| Якість | добре для чітких фото стандартного витягу / ДКП / договору з УК; розмиті фото й нестандартні документи — гірше | розуміє будь-які документи, пояснює, чого не видно |

У безкоштовному режимі сторінка завжди пише «Розпізнано безкоштовним OCR — звір поля з фото»: ПІБ, номер і площу
краще звірити з фото перед «Підтвердити» (поля можна виправити).

## Як працює

- **Голос** = «✅ У ДАХ» (колонка G реєстру / E нежитлових) + «Право власності» (F / D) — так само, як рахує «📊 Лічильник».
- «Підтвердити» вписує площу, ПІБ, телефон, «Право власності», «✅ У ДАХ» і фарбує рядок у зелений.
- Перед підтвердженням сторінка показує, що зараз у реєстрі, і попередження:
  ❗ не право власності, ❗ чужа адреса, ❗ № немає в реєстрі, інша площа, інший власник, «вже підтверджено».
  Поля можна виправити вручну.
- Інвестиційні / попередні договори внести не можна (кнопка неактивна).
- Кожне підтвердження — рядок у «Заявки» з посиланням на папку з фото («ДАХ документи» на Drive).
- `?stats=1` віддає лише суми по секціях і площу — без номерів квартир і ПІБ (як `votes.js`). Кеш 5 хв.

## Приватність

- Фото стискаються в телефоні до 2000 px і зберігаються лише на твоєму Google Drive.
- Безкоштовний режим: розпізнавання в межах твого Google Drive (тимчасовий документ одразу йде в кошик).
- З ключем Claude: фото йдуть у Claude API (Anthropic не використовує дані API для навчання).
- У коді немає ключа й персональних даних.
