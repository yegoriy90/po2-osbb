# Збір на резервне живлення (Google Apps Script)

Форма на **po2.kyiv.ua/zbir/** пише заявки в закриту Google-таблицю опитування, а сайт показує лише загальні цифри.
Номери квартир, імена й контакти бачить тільки власник таблиці.

Файл: `Code.gs`.

## Налаштування (один раз, ~10 хв)

1. Завантаж `po2_zbir.xlsx` на Google Drive → відкрий → **Файл → Зберегти як Google Таблиці**. Далі працюєш у новій Google-таблиці.
2. **Розширення → Apps Script** → видали порожній код → встав `Code.gs` → збережи (Ctrl+S).
3. Угорі вибери функцію **`setup`** → **Виконати** → дозволь доступ («Додатково → Перейти до проєкту»). З'явиться аркуш «Заявки».
4. **Розгорнути → Нове розгортання → ⚙️ Веб-застосунок**:
   - Виконувати як: **Я**
   - Хто має доступ: **Усі**
   - **Розгорнути** → скопіюй URL (закінчується на `/exec`).
5. Надішли URL Claude: він впише його в `zbirUrl` у `data.js`, і форма запрацює.

Після зміни коду: **Розгорнути → Керування розгортаннями → ✏️ → Версія: нова → Розгорнути** (URL не зміниться).

## Як працює

- Кожна заявка → рядок у «Заявки» (час, №, відповідь, сума, ім'я, контакт).
- Рядок квартири в «Опитування» оновлюється, якщо він ще порожній або контакт той самий (людина змінила відповідь).
  Якщо прийшла заявка з **іншим** контактом, рядок не перезаписується: у «Примітка» з'являється ⚠, розбираєте вручну.
- «Сплачено» (колонка G) ведете самі — сайт показує загальну суму сплаченого.
- Захист: не більше 5 заявок на квартиру на годину, приховане поле-приманка для ботів, «Так»/«Подумаю» без контакту не приймаються.
- `?stats=1` віддає лише суми по секціях (Так / Подумаю / Ні / обіцяно), медіану, «хмару» сум (сума, округлена до 500 грн → скільки квартир, без номерів) і сплачене. Кеш 5 хв.
