# «Поруч» — скрипт таблиці «ПО2 · Комерція (публічна)»

Що робить:
- сайт po2.kyiv.ua/poruch/ бере список закладів звідси (лише рядки з «Показувати = так»);
- форма «Додати заклад» на сайті додає заклад у «Заклади» **жовтим рядком з «Показувати = ні»**, контакт власника — в аркуш «Заявки» (на сайт не потрапляє), і надсилає тобі лист;
- ти перевіряєш, правиш, ставиш «так» — за 5 хв заклад на сайті (одразу — запусти `refresh`).

## Налаштування (один раз, ~5 хв)

1. Відкрий таблицю «ПО2 · Комерція (публічна)» → **Розширення → Apps Script**.
2. Встав вміст `Code.gs` замість того, що там є. Збережи (Ctrl/Cmd+S).
3. Угорі вибери функцію **`setup`** → **Виконати** → дозволь доступ (таблиця + надсилання пошти;
   «Додатково → Перейти до проєкту» — це твій власний скрипт). З'явиться аркуш «Заявки».
4. **Ввести в дію → Нове введення в дію → ⚙️ Веб-застосунок**:
   - Виконувати як: **Я**
   - Хто має доступ: **Усі**
   - **Ввести в дію** → скопіюй URL (закінчується на `/exec`) і надішли Claude — він під'єднає сайт (`poruchUrl` у `data.js`).

Публікувати таблицю в інтернеті **не потрібно**: сайт бачить лише те, що віддає скрипт.

Після зміни коду: **Ввести в дію → Керувати → ✏️ → Нова версія** (URL той самий).
