# ЖК «Паркові Озера 2»: створюємо ОСББ

Сторінка кампанії за створення ОСББ. Кожен власник, що підтримав ОСББ, додає світле вікно в намальований будинок (вікна розставлені випадково).

## Як оновлювати голоси
1. Завантажте свіжий реєстр (`registry_*.xlsx`) у корінь репозиторію. Його не комітять, він у `.gitignore`.
2. `python3 tools/build_votes.py registry_v10.xlsx`: скрипт перегенерує `votes.js`.
3. `node tools/build_og.js`: оновить відсоток на прев'ю для месенджерів (`img/og.png`).
4. Закомітьте `votes.js` і `img/og.png`.

У `votes.js` потрапляють лише суми: скільки квартир у ДАХ по кожній секції і загальна площа. Номери квартир, поверхи, імена й телефони на сайт не потрапляють, вікна підсвічуються випадково.

Налаштування в `data.js`:
- `sections[]`: поповерхова розкладка з табличок у холах (`first`, `layout: "2:3, 3-19:10, ..."`), `split`: розділені квартири (337-1, 337-2).
- `team`: контакти ініціативної групи по секціях (імена й Telegram).
- `current`: на якому етапі дорожньої карти ми зараз (з 0).
- `dahUrl`, `botUrl`: посилання на ДАХ і Telegram-бота. QR-коди лежать в `img/`.
